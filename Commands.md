All commands in baritone start with ".b" or "#"


EXAMPLE

.b help - Shows all ingame commands in chat

#goto X,Y,Z - Pathfind to that location


List

help - Shows all ingame commands

set - view or change settings

modified - List modified settings

reset - Reset all settings or just one

goto - Go to coordinate or block

proc - View process state information

version - view Baritone version

repack - Re-cache shunks

build - build schematic

schematica - Builds loaded schematic

come - start heading towards your camera

axis - Set a goal to the axis

forcecancel - Force cancel

gc - call System.gc()

invert - Run from goal

tunnel - Set a goal to tunnel in your current direction

render - Fix gliched chunks

farm - Farms nearby crops

chests - Display rememberd inventories

follow - Follow entity things

explorefilter - Explore chunks from a json

reloadall - reloads Baritones cache for world

saveall - Saves all cache

explore - explore things

blacklist - blacklist nearest block

find - finds block location

mine - mines block

click - open click

thisway - travel in your current direction

waypoints - manage waypoints

sethome - setshome waypoint

home - Make Home Goal with "path"

sel - worldedit commands

pause - pauses order

resume - resumes order

cancel - cancels order
